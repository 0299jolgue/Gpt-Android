# Android client

Esta pasta reserva a implementação do cliente Android visível para testes autorizados.

O cliente deve:

- mostrar claramente que está ligado ao Gpt-Android;
- pedir e manter apenas permissões necessárias;
- permitir emparelhamento iniciado pelo utilizador;
- enviar telemetria limitada (modelo, versão Android, bateria e estado de rede);
- mostrar o estado da ligação e permitir desligar o serviço.

Não deve implementar recolha oculta de mensagens/notificações, credenciais, gravações secretas, persistência furtiva ou controlo remoto arbitrário.
